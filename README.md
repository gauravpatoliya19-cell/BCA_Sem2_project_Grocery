# Grocery Store Website (BCA Sem 2 Project)

A responsive e-commerce grocery store website developed as a BCA Semester 2 project.

## Features
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktop screens.
- **Interactive Header Components:**
  - Search bar toggle
  - Shopping cart sidebar/drawer
  - User login popup form
  - Mobile hamburger navigation menu
- **Product Slider:** Responsive product carousel powered by Swiper.js with touch swipe, autoplay, and navigation controls.
- **Product Categories & Features:** Displays featured offerings, categories, customer blogs, and store information.
- **Font & Icon Integration:** Uses Font Awesome icons and Google Fonts (Poppins).

## Project Structure
```
├── css/
│   └── style.css       # Main stylesheet
├── imag/               # Product and banner images
├── js/
│   └── custom.js       # Interactive toggles and Swiper initialization
├── index.html          # Main HTML document
└── README.md           # Project documentation
```

## How to Run
Simply open `index.html` in any modern web browser or use a local development server (such as VS Code Live Server).
